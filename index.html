3 Steps to Your AI Bot

From zero to a working AI chatbot on Telegram.

1

Get a Bot Token

Message @BotFather on Telegram, create a bot, copy the token.

2

Configure

Paste the token in .env, pick your model, set the personality.

3

Deploy

docker-compose up -d — your bot is live and answering messages.

# Clone and configure cp .env.example .env nano .env # paste your bot token # Launch everything docker-compose up -d # Pull a model (first time only) docker exec ollama ollama pull llama3.2:3b # Done! Open Telegram and chat.
